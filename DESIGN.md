# TOLY — Character Design

## Identity

TOLY is a small, expressive fox built for a fast, playful endless runner. He should be instantly recognisable at phone-screen size and feel mischievous rather than aggressive.

## Signature look

- **Cap:** a soft five-panel running cap, worn forward, with a Solana-gradient front panel.
- **Glasses:** oversized black wraparound sunglasses with a subtle mint highlight.
- **Fur:** warm orange with cream muzzle, inner ears, and tail tip.
- **Outfit:** dark charcoal runner jacket with a narrow purple-to-mint stripe.
- **Expression:** confident smile while running; wide eyes or tilted glasses for danger and impact reactions.

## Solana colour palette

| Use | Colour |
| --- | --- |
| Solana purple | `#9945FF` |
| Solana mint | `#14F195` |
| Deep background | `#15111F` |
| Jacket charcoal | `#25222B` |
| Fox orange | `#F58A45` |
| Cream | `#FFF0D7` |

The cap should use a left-to-right gradient from Solana purple to Solana mint. Keep the rest of the character balanced and avoid placing any Solana wordmark or logo on him.

## Sprite direction

- Style: crisp, modern pixel-art game sprite.
- Framing: side view facing right, full body visible.
- Background: transparent.
- Base size: 256 × 256 pixels, designed to remain clear when displayed at 96–144 CSS pixels.
- The final sprite must contain no text, watermark, or background scene.

## Animation notes

The cap and tail must create a clear silhouette. During a run, the tail bounces gently and the cap brim moves slightly. Sunglasses stay on in every animation except the impact reaction, where they can tilt briefly.
